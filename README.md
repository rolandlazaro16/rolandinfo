# Immaculatha Lazaro Muro — Portfolio

Professional portfolio built with **Next.js** and **TypeScript**.

## Sections

- Hero & introduction
- About me
- Education (St. Hellen → Sunrise → Kirakala → SUA → Harvard)
- Skills (Economics, Finance & Budgeting, Lecturing)
- Experience (Government & NGOs — 3 years)
- Contact (WhatsApp & Email)

## Getting Started

```bash
cd "Portfolio Info"
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit `src/data/portfolio.ts` to update profile information.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
